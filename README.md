# 图兰的像素农场 🌾

胡美琳（图兰）的个人主页，像素农场互动版。

👉 **访问地址**：https://e-electron.github.io/self-introduction/

## 玩法
- 🌻 **公共菜园**（左侧5块地）：大家一起浇水，累计20次成熟解锁图兰信息
- 🪴 **我的小院**（右侧5块地）：你的专属地，自选种什么，浇8次成熟
- 🏠 **图兰小屋**：点击查看自我介绍
- 🏋️ **运动场**：点击查看健身日志
- 📚 **书架角落**：点击查看书单（亲密度90+解锁微信）
- 👗 右上角换装按钮：4套皮肤
- ☀️🌙🌧️ 天气切换：白天/夜晚/下雨

## 说明
- 外网版数据存本地 localStorage，换设备不互通
- AI 对话、漂流瓶、实时日程为内网功能
